# 🌟 Team Portal | Premium Glassmorphism Experience

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen?style=for-the-badge)](https://team-devika.vercel.app)
[![Tech Stack](https://img.shields.io/badge/tech-HTML%20%7C%20CSS%20%7C%20JS-blue?style=for-the-badge)](https://github.com/devikavinod224/Team)

A state-of-the-art web portal designed with high-end glassmorphism aesthetics, dynamic video backgrounds, and a professional developer team showcase. This project serves as a centralized hub for developer profiles and specialized API services.

Check out the live experience here: **[team-devika.vercel.app](https://team-devika.vercel.app)**

## ✨ Key Features

### 🔐 Dynamic Login System
- **Glassmorphism UI**: Beautiful frosted-glass interface with real-time blur.
- **GitHub Integration**: Automatically fetches profile avatars based on the entered username.
- **Cinematic Visuals**: Background video toggle with a premium floating control button.
- **Interactive Feedback**: Real-time loading states and toast notifications.

### 👥 Premium Developer Showcase
- **Animated Cards**: 3D-tilt enabled cards with mouse-tracking neon backlights.
- **Hierarchy System**: Custom badges for Main Developers and Assistant Developers.
- **Social Integration**: One-click access to GitHub profiles and interactive Discord tags.
- **Greyscale-to-Color Transitions**: Modern hover effects for profile portraits.

### 🎵 Spotify Canva API (Microservice)
- **Interactive Playground**: A full-featured sandbox to test Spotify Canvas video fetching.
- **iPhone Mockup**: Real-time video previewing inside a high-fidelity iPhone interface.
- **Professional Docs**: Comprehensive developer documentation for protobuf decoding and authentication.

## 🔧 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/devikavinod224/Team.git
   ```

2. **Navigate to the project**:
   ```bash
   cd Team
   ```

3. **Run a local server**:
   ```bash
   # Using npx serve
   npx serve .
   
   # Or using Python
   python -m http.server 3000
   ```

4. **Access the portal**: Open `http://localhost:3000` in your browser.
